# magda wedding

Create a stunning, elegant wedding invitation intro animation using Tailwind CSS, React, and Framer Motion. The intro should have two sequential phases:

Envelope Opening Phase:

Show a luxury textured white wedding envelope with embossed damask patterns, decorated with light blue lace on top.

In the center, place a realistic 3D cream-colored wax seal featuring custom initials ("L & M") inside a floral border.

Add a smooth click/tap or automatic trigger where the wax seal lifts up, and the envelope flap opens smoothly upwards, revealing a soft glowing white inner paper.

Transition to the Main Invitation:

As the envelope opens fully, seamlessly transition into a romantic castle gate or draped curtain animation that parts to reveal the main wedding landing page.

The background should feature a soft, hand-painted watercolor castle aesthetic in pastel blue and cream tones.

Display elegant typography for "The Wedding of Lucia & Matteo", along with date ("27 JULY 2027") and location ("Château de la Couronne, Nouvelle-Aquitaine, France").

Add subtle floating elements like falling petals and a sound/mute icon in the corner.

Make it fully responsive for mobile screens, extremely smooth with high-end luxury aesthetics, soft pastel color palette, and polished CSS transitions. use attachted video as reference.. and make similar
